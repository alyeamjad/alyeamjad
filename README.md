## Current Role

**Computer Vision & Robotics Engineer, Decom Robotics LLC**

Leading perception and system design for an autonomous laptop disassembly robot built on the UFactory xArm.

- Designed and own the complete ROS-based system architecture for the platform, including communication with the robotic arm
- Manage camera, hand-eye, and system-level calibration across the pipeline
- Defined the camera specification for the platform after evaluating shutter and focus behavior under motion. Rolling shutter and autofocus cameras introduce intrinsic drift that breaks calibration stability, so the system now runs on global shutter, fixed focus cameras
- Building detection and pose estimation for screws, ports, and components under production line conditions
